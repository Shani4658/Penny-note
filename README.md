# 💰 PennyNote

PennyNote is a modern personal finance management web application built using Next.js, TypeScript, Firebase, and AI-powered features. The application helps users manage expenses, track spending, organize financial records, and gain insights into their financial activities through a clean and responsive interface.

🌐 Live Demo: [https://penny-note.vercel.app/](https://penny-note.vercel.app/)

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/penny-note.git
cd penny-note
```

---

## 2️⃣ Install Dependencies

```bash
npm install
```

---

## 3️⃣ Configure Firebase

1. Create a Firebase project
2. Enable required Firebase services
3. Add Firebase configuration keys
4. Configure environment variables

---

## 4️⃣ Configure AI Services

1. Setup Google AI API keys
2. Configure Genkit integration
3. Add environment variables

# ▶️ Running the Project

Start the development server:

