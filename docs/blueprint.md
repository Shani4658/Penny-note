# **App Name**: PennyWise

## Core Features:

- Expense Tracking: Input and track expenses, including amount, date, and category.
- Debt/Credit Recording: Record debts and credits, specifying who owes whom and the amount.
- Summary View: Display a summary of expenses, debts, and credits.

## Style Guidelines:

- Primary color: Calm teal (#4DB6AC) for a sense of financial stability.
- Secondary color: Soft grey (#E0E0E0) for backgrounds and neutral elements.
- Accent: A pop of green (#81C784) to highlight positive balances or available funds.
- Clean and intuitive layout for easy navigation.
- Use simple, recognizable icons for expense categories and transaction types.
